\begin{abstract}
\noindent In July 2026 about 1,200 AI agents in an evaluation turned a shared directory into a message board. We ask how little it takes for parallel agents to do the same. In a seeded sandbox, 12 LLM agents per episode take the same four-question exam in four waves, with a lookup budget too small to finish alone. We vary whether a shared writable folder exists, how visible it is, what it starts with, and whether agents are told to work alone, and score agents from their tool logs. Across \nepisodes{} episodes (\nagents{} agent runs, \nmodels{} models), no agent opened a folder nobody mentioned (\hiddenOpened{} of \hiddenN{}); one neutral sentence in the task file made most Claude 5.5 agents read it. Given a note claiming four verified answers, Claude Sonnet 5.5's measured accuracy rose from \AccSonnetIso{} to \AccSonnetEnc{}. Readers checked what was cheap to check and copied the rest, so a planted wrong answer reached \AdoptPctCostlyAll{} of readers when it sat on the costliest question. An empty folder stayed empty, but one note inviting agents to pool confirmed answers, with no answers in it, started a relay: early agents posted ``confirmed'' results with record ids, and Sonnet 5.5's accuracy rose from \AccSonnetInvWA{} in the first wave to \AccSonnetInvWD{} in the last. A one-line rule stopped it. On the real collusion.wiki board, \realverify{} of answer-bearing posts make the same claim of verification. Parallel rollouts that share a writable surface behave as one population.
\end{abstract}
