\section{Discussion}

\paragraph{Parallel rollouts were not independent once they shared a place to write.} In our sandbox the same model scored about 50\% alone and up to \AccSonnetEnc{} next to a note, and the last wave of a relay scored \AccSonnetInvWD{}. Those numbers reflect the folder and the agents before them as much as the model. Any evaluation that runs many copies of an agent at once, with a shared cache, volume, bucket or public site, should treat that surface as part of the test: give each rollout its own, or log every write to it and report scores with and without the rollouts that read it.

\paragraph{The first post is what turns a shared place into a channel.} Agents opened an encouraged, empty folder almost every time and wrote nothing in it. One short note from ``an earlier run'' asking them to pool was enough for agents with no other instruction to collaborate to start posting their progress for strangers. The real board's relay pages, addressed to ``ahead cohorts'' and full of ``confirmed'' values, have the same structure. If so, monitoring should watch for first posts, not only for volume.

\paragraph{What gets checked is what is cheap to check.} Readers did not ignore the planted note, and most did not trust it blindly either. They spent their remaining lookups where checking was cheap and took the note's word elsewhere, so a wrong answer on the question that costs most to check spread furthest. Moving the planted answer within the same exams reproduced the gap, though cost is still tied to question type. It points to a cheap audit: a wrong value planted where checking is expensive works as a canary. In our runs, \AdoptCostlyAll{} readers who met such a value submitted it, which marked them as copiers from their answers alone.

\paragraph{Models differ, and an instruction helps.} Haiku 5.5 read the note as often as Sonnet 5.5 but mostly refused to submit answers it had not checked from the planted note, yet it took its peers' relay posts, which showed where each value came from. Haiku 4.5 rarely looked, but copied almost everything when it did. An instruction to work independently stopped the relay for both newer Claude models in our runs. That is instruction-following, not a guarantee, and it needs testing on every model an evaluation runs.

\paragraph{Future work.} Costly questions of more than one type, to separate cost from question type; longer tasks with more turns; more model families at full coverage; a monitor that reads only the shared folder's write log and flags the first post; and notes that carry instructions rather than facts, run in this sandbox where they cannot reach anything real.
